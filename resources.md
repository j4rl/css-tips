# Resources

References and tools for deeper learning.

## Documentation

- [MDN Web Docs](https://developer.mozilla.org/en-US/docs/Web/CSS): CSS reference and guides
- [Web.dev](https://web.dev/learn/css/): articles on performance and modern CSS
- [CSS Working Group drafts](https://www.w3.org/Style/CSS/specs/): cutting-edge feature specs

## Tools

- [Can I Use](https://caniuse.com/): browser support tables
- [WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/): contrast testing
- [Open Props](https://open-props.style/): design tokens and utility inspiration

## Reading list

- [A Book Apart: CSS for Responsive Web Design](https://abookapart.com/products/css-for-responsive-web-design): practical responsive CSS
- [Every Layout](https://every-layout.dev/): layout patterns by Heydon Pickering and Andy Bell
