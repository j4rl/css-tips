# CSS-tips

CSS tips and a structured guide from fundamentals to advanced techniques.

## Start here

- New to CSS: see [learning-path.md](learning-path.md)
- Quick wins and patterns: see [tips.md](tips.md)
- Daily bite-sized tips: see [css_tip_of_the_day.md](css_tip_of_the_day.md)
- Core reference: start with [basics.md](basics.md) and [layout.md](layout.md)

## Repository map

- [basics.md](basics.md) - selectors, cascade, box model, units, and sizing
- [layout.md](layout.md) - normal flow, flexbox, grid, positioning, and containment
- [typography.md](typography.md) - fonts, text flow, readability, and variable fonts
- [colors.md](colors.md) - color spaces, contrast, gradients, and tokens
- [responsive.md](responsive.md) - media queries, container queries, and fluid sizing
- [effects.md](effects.md) - shadows, filters, blend modes, and masking
- [animations.md](animations.md) - transitions, keyframes, timing, and performance
- [advanced.md](advanced.md) - layers, scope, Houdini, and new features
- [architecture.md](architecture.md) - naming, layering, and scaling strategies
- [performance.md](performance.md) - rendering cost, paints, and optimization
- [accessibility.md](accessibility.md) - focus, motion, and color accessibility
- [css_tip_of_the_day.md](css_tip_of_the_day.md) - linked daily tips organized by topic
- [daily-tips/](daily-tips/) - individual tip files used by [css_tip_of_the_day.md](css_tip_of_the_day.md)
- [resources.md](resources.md) - references and tools
- [glossary.md](glossary.md) - core CSS terms

## Goals

- Be practical: show the simplest working pattern first
- Be modern: cover cutting edge CSS features and where they fit
- Be reliable: prefer patterns that work across browsers, with fallbacks
