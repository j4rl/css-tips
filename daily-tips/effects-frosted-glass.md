# Frosted glass
Combine blur and transparency for a glass effect.

```css
.glass {
  background: rgba(255, 255, 255, 0.2);
  backdrop-filter: blur(12px);
  border: 1px solid rgba(255, 255, 255, 0.3);
}
```

Why it helps: layered depth without heavy imagery.
